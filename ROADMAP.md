## Правила

- **R1.** README = прошлое (спеки, прогоны, sha). ROADMAP = будущее (очередь, статусы, реестр). Ничего не дублируем, ссылаемся.
- **R2.** Любая новая идея — сначала строка в Backlog (статус «новая»), потом волна. Волна на старте получает «в работе», на сдаче — «сдано» + sha.
- **R3.** Один фронт: одновременно в работе ровно одна волна.
- **R4.** Отменённое не стираем: статус «отменено» + причина (история решений дороже чистоты списка).
- **R5.** Чистки — отдельные волны, не вперемешку с фичами.
- **R6.** Каждая сдача ритм-линии: обновить реестр (sha/sw) + запись в README (как делаем).

- Новая идея → строка в Backlog с ID вида `B-NN` (следующий свободный — B-32).
- ID уникален сквозным образом по ВСЕМ рядам документа (активные/сданные/отменённые) — переиспользование запрещено: ID нужен, чтобы сослаться позже (R4). - Старт волны → статус «в работе»; сдача → «сдано» + строка в реестре (для ритм-линии — с sha/sw).
- Раз в несколько волн перечитываем порядок — он живой, не догма.

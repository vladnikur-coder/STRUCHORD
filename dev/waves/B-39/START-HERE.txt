ЧТО ДЕЛАТЬ (4 шага, по порядку)
----------------------------------------------------------

Шаг 1. Положи этот комплект рядом с рабочим STRUCHORD.html
       (важна папка B-39-tests целиком — apply_patch.py читает
        из неё файлы stage0_block.js … stage6_block.js).

Шаг 2. Применить патч к АКТУАЛЬНОЙ версии приложения:

       python3 B-39-tests/apply_patch.py STRUCHORD.html --check
       python3 B-39-tests/apply_patch.py STRUCHORD.html

       --check сначала проверяет якоря и НИЧЕГО не меняет.
       Если что-то не нашлось — скрипт напишет, какой именно якорь.
       Резервная копия создаётся автоматически.
       Откат:  python3 B-39-tests/apply_patch.py STRUCHORD.html --uninstall

       НЕ используй git apply на рабочей версии: она ушла вперёд
       от справочного снимка 0.691 на тысячи строк. git apply
       проверен ТОЛЬКО на точном снимке 0.691.

Шаг 3. Прогнать полный корпус тестов проекта (131 набор)
       и тесты волны (см. B-39-tests/README.md).

Шаг 4. Обязательный релизный шаг (правила R7 и R6):

       python3 B-39-tests/bump_release.py STRUCHORD.html sw.js ROADMAP.md \
           --wave "B-39 · Режим «Клавиши»"

       Можно сначала с --dry-run — просто посмотреть результат.
       Скрипт поднимет видимую версию, CACHE_NAME в sw.js,
       посчитает sha256/размер и вставит строку в реестр релизов.
       HTML и sw.js выкладывать ПАРОЙ. Коммит — только в ветку
       текущей Arena-сессии (R9).

       Также добавь в README.md приложения три готовых абзаца
       из PATCH-NOTES.md (раздел «Что надо добавить в README.md»).

ЧТО ПОЛУЧИЛОСЬ (коротко)
----------------------------------------------------------

- Гитара или Клавиши как параметр дорожки; простой микшер с «+», «⋯»,
  громкостью, M/S; активная дорожка; строки перетаскиваются.
- Старые песни автоматически превращаются в одну гитарную дорожку
  и звучат как раньше. Новая песня начинается без дорожек.
- Клавишные размеры 25/37/49/61/76/88 (по умолчанию 61), свой размер
  на дорожку, свои позиции аккорда с вариантами.
- Свой синтез пианино (6 парциалов + молоточек) и простой тон.
- Панель «Аккомпанемент»: 6 типов рисунка, дробность, свинг,
  «Рисунок на такт» с подсветкой, применение к ячейке или секции.
- Кнопка «Бой/перебор» на клавишной дорожке становится
  «Аккомпанемент»; на гитаре всё возвращается обратно.
- Экспорт ВСЕХ дорожек отдельно: GPX — настоящий нотный стан
  с абсолютными высотами; GP5 — виртуальный широкий строй;
  MIDI — SMF format 1, program 0 у клавиш; .struchord — полная модель.

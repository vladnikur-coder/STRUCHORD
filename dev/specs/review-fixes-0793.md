# 0.793 — правки по ревью преподавателя (2026-11-04)

Ревью пяти пунктов B-39 (расположения/голосоведение/автоакцент); все пункты
сначала подтверждены по коду, затем исправлены. Патч:
`dev/tools/patch-review-fixes-0793.py` (24 якоря).

1. **Потолок размаха правой руки = 15 п/т единый** (`VL_MAX_SPAN`; в
   `inversionCandidates` было 16). Это потолок генератора, не норма руки:
   «играбельно» из текстов убрано; оговорка пользователю: удобство зависит
   от размера руки, темпа и способа исполнения, широкие интервалы могут
   потребовать арпеджирования или распределения между руками — этот предел
   их удобство не оценивает. Число клавиш инструмента руку не увеличивает.
2. **«Широко» = раздвижение теми же нотами** (одна нота RH на ±октаву,
   исходная убирается; состав/число голосов/бас сохранены). Раньше нота
   добавлялась — это было удвоение плотности. Предлагается только при
   спане > базового и ≤ 15; иначе широкого нет (C-трезвучие на 88 кл.:
   C–G–E′ = 16 п/т — широкого нет). «+октава» (удвоение) — отдельным
   приёмом позже, не под этой кнопкой.
3. **Подписи без «обращения всей гармонии»**: счётчик «Правая рука: i/n ·
   плотно/широко», стрелки «Предыдущее/Следующее расположение», aria
   «Расположение правой руки … Бас не меняется»; если широкого нет — явно
   «плотно, широкого нет».
4. **parallelPerfects**: баг — `min(mod12(d), 12−mod12(d))` ∈ 0..6, ветка
   `=== 7` мёртвая, параллельные квинты не распознавались при обещанном
   запрете. Теперь направленные классы mod12 (7→7 квинта, 0→0
   октава/унисон), неподвижный голос — не параллель, противоход — не
   параллель. Штрафы мягкие раздельные: квинты ×2, октавы/унисоны ×4, без
   запрета (поп/рок/джаз допускают параллели; приоритет — состав,
   удобство рук, верхняя линия). Бас вне движений (RH-only): «бас октавой»
   и удвоение мелодии штрафом не задеваются. Строгий запрет — отдельным
   учебным режимом классического голосоведения, не здесь.
5. **Автоакцент 13/9 (0.789) — опция `endAccent`**: новые дорожки — выкл;
   старые песни (поля нет) — вкл, звучание не меняется. Выключение не
   убирает 9/13 из аккорда, только доп. выделение. Добавленная нота
   проходит проверку размаха RH (≤ 15), иначе пропускается. Ручные партии
   не трогаются. UI: «Выделять 13/9 в конце такта» (#b39AutoEndAccent).

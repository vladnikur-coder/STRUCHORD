# B-119 rework · 0.792 — стрелки по обращениям + тоггл «Плотно | Широко»

Дата: 2026-11-04. Ветка: `arena/bf99fe44-struchord`. Версия: 0.792 (`ver 0.792` + `struchord-v792`, R7). 0.791 (карточки) отклонён владельцем и откачен revert-коммитом `5dfc1bb`.

## Направление владельца (2026-11-04)

- «Никаких карточек нет, я их не вижу» → карточки убрать совсем.
- При наведении на аккорд панель клавиш показывает, как его сыграть; там должны быть **кнопки смены обращения**.
- **По умолчанию стандартный вид**: для C — C E G и бас C; для Am — A C E и бас A (основное положение, правая рука с корня).
- Стрелки переключают обращения; плюс **переключатель плотно-широко**.
- «Варианты, которые предлагает приложение, должны быть играбельны для реального пианиста» — поэтому список = канонические обращения в одной октаве правой руки (размах ≤ 16 полутонов), а не регистровые копии.

R8-резюме подтверждено `final=yes`: широко = верхняя нота правой руки +12 (октава), только на 61+ и если влезает; ручной выбор поверх авто и сохраняется.

## Реализация

Патч `dev/tools/patch-b119b-voicing-inversions-0792.py` (16 якорей в `STRUCHORD.html`):

1. **`voicingVariantStructure(chord,key,range)`** → `{list, slots}`:
   - `list` = обращения из `inversionCandidates`, отфильтрованные в первую октаву правой руки `[lo, lo+12)`, **основное положение первым** (по `rootPc` формулы; C → `[36,48,52,55]`, Am → `[45,57,60,64]`), затем в хвосте «широкие» копии (верх RH +12) при `size>=61`, если влезает в `[low, min(high,84)]` и `base.length < handLimit`, без дублей;
   - `slots[i] = {base: listIdx, wide: listIdx|-1}` — карта обращения ↔ его широкий вариант.
2. **`listVoicingVariants`** = `structure.list` — единый список для UI, ручного выбора (`linkedSelection`, fallback 2048) и звука (voicingProvider, selectedShape, авто-модуль, renderKeysVoicingSVG): ручной индекс резолвится одинаково в схеме/звуке/превью/экспорте.
3. **`stepVariant(delta)`** — стрелки ‹ › ходят по `slots` по кругу, сохраняя блок плотности; поверх авто первое нажатие берёт основное (вперёд) / последнее (назад) обращение вручную.
4. **`toggleDensity()`** + toggl `#b39KeysDensity` («Плотно»/«Широко») в nav панели; виден только когда есть широкие слоты (класс `has-wide`); счётчик: «Ручная/Авто · обращение i/N · плотно/широко».
5. `inversionCandidates` (авто-голосоведение 0.790) не изменён. R7: `ver 0.792` + `struchord-v792`.

## Замечание по совместимости

Ручные индексы, сохранённые в версиях до 0.792, переинтерпретируются по новому порядку (обращения, основное первым) — осознанно, по направлению владельца. Песни без ручных индексов и без галочки `linkedVoicings` звучат как раньше; `exactNotes` побеждает всегда.

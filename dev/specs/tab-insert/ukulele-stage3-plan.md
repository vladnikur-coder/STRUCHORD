# B-39 Укулеле · Этап 3 — 4-струнная «Таб-вставка»

Дата: 2026-11-23. Статус: **волны 1–2 (0.870–0.871) сделаны**, впереди волна 3 (0.872).

## 1. Что есть сейчас

«Таб-вставка» (B-12.12) — **гитарный домен песни**, привязанный к строю песни:

| Слой | Где | Факт |
|---|---|---|
| Данные | квадрат `sq.type === 'tab'` (`sq.beats`, `sq.notes`) и ячейка `ev.isTab` (`ev.span`, `ev.tabNotes`) | всегда 6 струн: `string` 0..5, 0 — низкая струна |
| Санитайзер | `tabInsertCleanNotes()` (~25228) | `string` 0..5, лад 0..`TAB_INSERT_MAX_SAVE_FRET` (30) |
| Редактор | `renderTabInsertEditor()` (~28740) | резервный список струн жёстко `[0..5]`; основной ввод — alphaTab-стан |
| Рендер | `tabAtBuildScore()` (~27674), `tabAtTuningNotes()` (~27582) | строй песни, 6 нот, `staff.stringTuning` |
| Миниатюра | `tabThumbRender()` (~25466) | тот же `tabAtBuildScore`, рисуется alphaTab |
| Звук | `playTabNotesAt()` (~50466) → `songLegacyStringFreqs()` | 6 частот строя песни + каподастр |
| Видимость | CSS `html.b39-ukulele-mode` (~33392–33394) | на укулельной дорожке `.tab-btn`, `.add-tab-btn`, `.chord-wrapper--tab` скрыты |
| Экспорт | GP5 / GPX·GPIF / MIDI | вставка выгружается как 6-струнная гитара |

Строи укулеле уже есть и **переиспользуются как есть** (`PART_UKULELE_TUNINGS`, ~68373,
порядок струн 4→1: `['G4','C4','E4','A4']` для high-G), потолок лада — `PART_UKULELE_MAX_FRET = 15`,
тембр — `PART_TIMBRE.ukulele` (нейлон, ~68410).

## 2. Предлагаемое решение: явный домен вставки

Добавляются **необязательные** поля; их отсутствие означает прежнее поведение (гитара, строй песни).
`schemaVersion` не меняется, старые песни читаются и сохраняются бит-в-бит.

| Место | Поле | Значения | По умолчанию |
|---|---|---|---|
| квадрат | `sq.tabInstrument` | `'guitar'` \| `'ukulele'` | отсутствует = гитара |
| квадрат | `sq.tabTuning` | id пресета (`uke-high-g`, `uke-low-g`, `uke-baritone`, `uke-canadian`) | отсутствует = строй песни |
| ячейка | `ev.tabInstrument`, `ev.tabTuning` | то же | то же |

Правила:

1. **Создание** — домен = инструмент активной дорожки на момент создания вставки; строй = её пресет.
2. **Струны и лады** — укулеле: `string` 0..3, лад 0..15; гитара/бас: `string` 0..5, лад 0..30 (как сейчас).
   Санитайзер получает домен; неизвестный/битый домен трактуется как гитарный — данные не теряются.
3. **Видимость** — на дорожке X видны и редактируются только вставки домена X, чужие скрыты
   (ровно как сейчас гитарные скрыты на укулеле). Лента подчиняется тому же правилу — сейчас она
   расходится с редактором: правила `html.b39-ukulele-mode` не покрывают `.tl-cell--tab`.
4. **Звук** — 4 частоты из строя домена (порядок 4→1, high-G учитывается как позиция, а не высота)
   + тембр `PART_TIMBRE.ukulele`; гитарная вставка звучит ровно как сейчас.
5. **Рендер и миниатюра** — alphaTab со строем домена: 4 струны, лады 0..15; картинка использует
   исправления 0.869 (все такты + линейка долей по реальным координатам alphaTab).
6. **Структурные операции** — клонирование, копирование, перенос между секциями, смена размера
   (`tabInsertConvertMeter`), объединение/разрезание секций обязаны переносить домен вместе с нотами.
7. **Экспорт** — 4-струнная вставка → GP5 / GPX·GPIF / MIDI с уке-строем и GM 24 (Nylon Guitar);
   гитарная — без изменений.

| 0.870 · W1 ✅ | модель + санитайзер + видимость + редактор (4 струны, 0..15) + alphaTab/миниатюра + звук | можно создать, отредактировать, услышать 4-струнную вставку на укулельной дорожке |

## 4. Обязательные тесты

- **Совместимость:** песня с 6-струнной вставкой открывается и сохраняется бит-в-бит (`string` 0..5 целы).
- **Границы домена:** 4 струны и лад 15 принимаются, струна 4 и лад 16 у уке-вставки отбрасываются.
- **Видимость:** на укулельной дорожке видны только уке-вставки (редактор + Лента).
- **Звук:** high-G — 4-я струна звучит выше 3-й (частота G4 > C4), тембр отличается от гитары.
- **Структура:** клонирование/перенос/смена размера сохраняют `tabInstrument` и `tabTuning`.
- **Регрессия:** гитарная вставка на гитарной дорожке не изменилась ни в данных, ни в картинке.

## 5. Решения владельца (подтверждены 2026-11-23)

1. **Привязка домена — вариант A, явные поля.** `sq.tabInstrument` / `sq.tabTuning` и
   `ev.tabInstrument` / `ev.tabTuning`; без них вставка читается как гитарная со строем песни.
   Неявная трактовка по активной дорожке (B) и копии по дорожкам (C) отклонены.
2. **Строй — id пресета + живой строй дорожки.** В вставке хранится `uke-high-g` и т.п.,
   при отрисовке берётся текущий строй дорожки (как в Guitar Pro); снимок строя отклонён.
3. **Чужие вставки — показывать серыми, только для чтения.** Вставка другого инструмента видна
   на активной дорожке, но не редактируется (вместо полного скрытия, как было в 0.866).
4. **Порядок работ:** сначала 0.869 (миниатюры: все такты + линейка счёта по координатам
   alphaTab), затем Этап 3 волнами 0.870 → 0.872.

## 6. Что сделано в 0.870 (волна 1)

| Слой | Реализация |
|---|---|
| Домен | `tabInsertDomainFrom()` / `tabInsertDomainPatch()`: `{instrument, tuning, strings, maxFret}`; гитара — 6 / 30 / строй песни, укулеле — 4 / `PART_UKULELE_MAX_FRET`, пресет из `PART_UKULELE_TUNINGS` (`uke-*`), битый id → High G |
| Дорожка | `tabInsertActiveInstrument()` (`StruChordTracks.state()`), `tabInsertTuningFromTrack()` переводит `trackTuning.id` (`high-g`) в пресет «Партий» (`uke-high-g`) |
| Данные | `sq.tabInstrument`/`sq.tabTuning`, `ev.tabInstrument`/`ev.tabTuning`; пишутся только у укулеле — гитарные вставки остаются байт-в-байт |
| Санитайзер | `tabInsertCleanNotes(raw, beats, ts, domain)`: `maxString = strings-1`, `maxFret = domain.maxFret`; без домена — прежние границы |
| Редактор | `editor.domain`, список струн `Array.from({length: domain.strings})`, `max="${domain.maxFret}"`, клампы курсора/клика/выделения по `tabAtStringsCount()` |
| Стан и миниатюра | `tabAtBuildScore(…, {domain})` → `stringTuning` пресета + кламп `note.string`; `tabThumbSpecFrom(notes, beats, ts, domain)` → `spec.i`/`spec.g`, ключ кэша различает инструмент и строй |
| Звук | `tabInsertStringFreqs(domain)` (High G ре-энтрантный: G4 392 Гц) + `PART_TIMBRE.ukulele` в `tabTechSoundOptions(…, domain)` |
| Видимость | CSS-скрытие 0.866 снято; чужая вставка — `is-foreign` (opacity 0.55, `pointer-events: none`, без `onclick` и ручки ресайза) |
| Структура | `addTabInsert`, `cloneTabSquare`, `cloneSection`, клон линейки Ленты, смена размера, `tabCommitInlineInsertion` сохраняют домен |
| Файл | `serializeCurrentSong` пишет домен, `sanitizeSongData` его валидирует (мусор → гитара) |

## 7. Что сделано в 0.871 (волна 2)

| Слой | Реализация |
|---|---|

| GP5 / GPX / GPIF | укулельная дорожка «Табы (укулеле, High G)»: 4 струны, строй вставки, капо 0, GM 24; GPIF пишет `FretCount 15` |
| Исходники писателей | укулельные ветки 0.866 перенесены из встроенных рантаймов в `dev/gp5-writer.js` и `dev/gpif-writer.js`, рантаймы пересобраны — повторная вставка больше не теряет поддержку |
| MIDI | по дорожке на каждую укулельную настройку (GM 24), маршрутизация по домену, `tabInsertCleanNotes(..., domain)`, высоты по строю вставки |
| Лента и закреп | правок не нужно: общий `renderTabInsertHtml` даёт `tab-insert--uke`, линейку счёта и серую чужую вставку; закреплено проверкой |

Осталось на 0.872 (волна 3): реальные песни (High G / Low G / баритон / Canadian), миграционная
проверка старых файлов бит-в-бит, связка «вставка ↔ партия» (перенос материала в 4-струнную партию
и обратно), документация.

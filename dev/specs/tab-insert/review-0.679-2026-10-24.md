# Проверка сборки 0.679 «Удобство как в Guitar Pro»
## Отчёт для владельца и задание агенту

Проверено: 2026-10-24, `STRUCHORD.html`, **ver 0.679**, 5 490 082 байт, md5 `9b8fe2d3994e2a6fab4785e685dbe708`.
Метод: живой запуск в Chromium 1600×1000 и 1500×950 — как на компьютере, без телефона. Сценарий: новая песня → секция «Куплет» → «+ Таб» → набор нот → «Применить» → экспорт → **обратный импорт** того же файла. Экспорт проверен не «на глаз», а чтением байтов: `.gp5` разобран настоящим alphaTab 1.8.4 (тем же движком, что внутри приложения, но запущенным отдельно), `.mid` — разбором структуры SMF.

---

## Вердикт

**Файлы — да. Удобство — нет.**

- **Экспорт починен и проверен числами.** Три прошлых блокера (струны со сдвигом, строй «пресетом», отсутствие MIDI) закрыты: в `.gp5` ноты лежат на 6-й и 5-й струнах, лады 0/3/0/3, звучат E2-G2-A2-C3; строй E standard; `.mid` — настоящий format 1 с правильными нотами. Подробности в §6.
- **Обе вещи, которые вы назвали, действительно не работают.** ⌥(Option)+↑/↓ ноту на другую струну не переносит; удалить такт можно только `Ctrl+−`, а `Ctrl+Del` (как в GP) — нет. Причины найдены в коде, они разные (§2).
- **Найдена третья, не названная вами, но самая обидная причина «неудобно»:** пробел закрывает редактор и **стирает набранное**, потому что после открытия фокус стоит на кнопке «Отмена». В GP пробел — play/pause (§3.1).
- **Панель кнопок на компьютере спрятана намеренно** (в коде так и написано: «Как в Guitar Pro: на компьютере — только стан и клавиатура»). Посылка неверная: в GP8 палитра слева есть и вызывается по F2, а мышью там делают половину работы (§3.3).

Счёт по официальной таблице GP8: из **47** действий, которые нужны для гитарной строчки, в 0.679 работают **21**, не работают **21**, три работают частично, два я не проверял. Это и есть «не как в GP».

## 2. Две вещи, которые вы назвали

### 2.1. ⌥(Option)+↑/↓ не переносит ноту на другую струну (P0)

**Что происходит:** нота стоит на 6-й струне, вы жмёте ⌥+↑ — ничего. Модель ноты не меняется: `{start:0, string:0, fret:3}` до и после. То же с ⌥+↓.

**Причина в коде (не «клавиша не доходит», а её просто не обрабатывают):** обработчик клавиш редактора — `tabGpKey`, строка **22277**. Там есть ветка «нажат Option/Alt»:

```
if (event.altKey && !cmd && !ctrl) {
  if (key === 'ArrowLeft' || key === 'ArrowRight') { … tabGpMove … return true; }
  return false;          // ← сюда попадают ↑ и ↓
}
```

То есть ⌥+←/→ (сдвиг по времени) есть, а ⌥+↑/↓ нет вовсе.

**Как в Guitar Pro 8 (официальная таблица):** `⌥↑` = **Move Up**, `⌥↓` = **Move Down** — нота переезжает на соседнюю струну с тем же ладом. Есть и второй, реже нужный вариант: `⌥⌘↑/↓` = Move Note Up/Down on Staff (изменить высоту, не меняя струну).

**Что должен сделать агент:** в той же ветке `altKey` добавить `ArrowUp`/`ArrowDown` и переносить ноту под курсором (или все ноты выделения, если выделение есть) на соседнюю струну: ⌥↑ — струна выше, к 1-й (в модели `string` **+1**), ⌥↓ — струна ниже, к 6-й (`string` **−1**); в пределах 0…5. **Лад сохранять.** Звук — как у ⌥+←/→ (`playTabNote`). Правку проводить через существующий `tabGpEdit(...)` — он уже умеет откатывать неудачную правку и держит историю.

**Приёмка:**
1. Поставьте «3» на 6-й струне → ⌥↑ один раз → нота на 5-й струне, лад 3, звук слышен.
2. ⌥↑ ещё три раза → 4-я, 3-я, 2-я струна.
3. На 1-й струне ⌥↑ не делает ничего и не выдаёт ошибку.
4. Выделены три доли (`Shift+→` ×2) → ⌥↓ переносит все три.

### 2.2. Выделенный такт нельзя удалить (P0)

**Что происходит:** `Ctrl+Delete`, `Shift+Delete`, `Ctrl+Shift+Delete`, `Backspace` — такт не удаляется и ничего не сообщает. Удаляет только `Ctrl+−` (в тестах 2 такта → 1).

**Как в Guitar Pro 8:**

| Действие GP8 | Mac | Windows | В 0.679 |
|---|---|---|---|
| Delete Bar — удалить такт | `⌃-` (Ctrl+минус) | `Ctrl+Del` | ✅ `Ctrl+−` есть, `Ctrl+Del` нет |
| Delete the Beats — удалить доли такта | `⌘-` | `Shift+Del` | ✅ `⌘/Ctrl+−` есть, `Shift+Del` нет |
| Delete — удалить выделенное | `⌦` | `Ctrl+Shift+Del` | ❌ нет |
| Delete Note — удалить ноту | `⌫` | `Backspace` | ⚠️ вместо удаления ставит **паузу** |

**Вторая половина проблемы:** в 0.679 **нельзя выделить такт**. Выделение есть только по долям (`Shift+←/→`), и «удалить такт» = удалить текущий такт без всякого выделения. В GP сначала выделяют такты (`⇧⌘→` по такта́м, `⇧⌘↘` до конца), потом жмут `Ctrl+Del`.

**Что должен сделать агент:**
1. `Ctrl+Del` и `⌘+Backspace` → `tabGpDeleteBar` (функция уже есть, строка **22037**).
2. `Shift+Del` → удалить доли (`tabGpDelete(e, true)`, **21915**) — как «Delete the Beats» в GP.
3. Простое выделение тактов: `⇧⌘→` / `⇧⌘←` расширяют выделение на такт вперёд/назад, `Ctrl+Del` удаляет все выделенные такты, `Esc` снимает выделение.

**Приёмка:** в вставке 2 такта, во втором — нота. Ставите курсор в первый такт → `Ctrl+Del` → остался один такт, нота второго сохранилась. Выделили оба (`⇧⌘→`) → `Ctrl+Del` → пустой стан, одна кнопка «Отменить» возвращает оба.

## 3. Пять находок, которых вы не называли, но они бьют по «удобству»

### 3.1. Пробел закрывает редактор и стирает набранное (P0 — риск потери работы)

**Проверено:** сразу после открытия редактора `document.activeElement` — это **кнопка «Отмена»**. Пробел нажимает сфокусированную кнопку → редактор закрывается. Если вставка была новая и пустая, она вообще исчезает из песни.

**В GP** `Space` = Play/Pause, `⇧Space` = играть с начала. Это одна из самых частых клавиш.

**Что должен сделать агент:** после открытия редактора переводить фокус на стан (`tabAtHostEl.focus()`), перехватывать `Space` (`preventDefault`) и запускать воспроизведение вставки, а кнопке «Отмена» не давать срабатывать от пробела. Заодно: `Enter` на сцене нот в GP = ввод ноты, `Esc` — снять выделение.

**Приёмка:** набрали 4 ноты → пробел → играет вставка, окно на месте, ноты на месте; ещё раз пробел — пауза. Второй вариант проверки: 10 нажатий пробела подряд — ничего не потеряно.

### 3.2. `Shift+↑/↓` не расширяет выделение, а схлопывает его (P1)

**Проверено:** `Shift+→` дважды даёт выделение `{0,0}–{0,2}`. Нажали `Shift+↓` — выделение стало точкой `{0,1}–{0,1}`.

**В GP** `⇧↑` / `⇧↓` = **Select Beat** — расширить выделение на долю вверх/вниз по струнам. Это второй по частоте способ выделить созвучие.

**Что должен сделать агент:** в ветке Shift+↑/↓ двигать только «фокус» выделения (по струне), не трогая «якорь». Выделение в модели должно стать прямоугольником «доли × струны».

### 3.3. На компьютере спрятана вся панель кнопок (P1)

В CSS, строка **5354**:

```css
/* Как в Guitar Pro: на компьютере — только стан и клавиатура. */
@media (min-width: 46.0625rem) and (hover: hover) and (pointer: fine) {
  .tab-tools { display: none; }
}
```

Последствия на экране 1600×1000: кнопки `[data-tab-gp]` («Выделить», «Копировать», «Вырезать», «Вставить», «Доля +», «Доля −», «Такт +», «Такт −») имеют размер **0×0**, кнопки «Лад», «Доля», «Струна», «Длительность», «Пауза», «Удалить» тоже не видны, и вместе с ними исчезает **индикатор струны** («6 (6-я)»).

**Это неверная посылка.** В Guitar Pro 8 палитра слева — основной способ работы, она вызывается по `F2`, и в ней 10 подписанных групп. Мышь в GP — не «режим планшета». Прятать панель именно на компьютере — ровно наоборот.

**Что должен сделать агент:** показывать `.tab-tools` на десктопе (можно одной компактной строкой), обязательно вернуть индикатор струны; на телефоне оставить как есть.

### 3.4. Кнопки обещают клавиши, которых нет (P1)

В палитре «Приёмы» у каждой кнопки в подсказке напечатана клавиша — и **четыре из них не работают**:

| Кнопка | Обещает | Проверено |
|---|---|---|
| Лига | `L` | ❌ ничего |
| Лиги позиции | `⇧L` | ❌ ничего |
| Бенд… | `B` | ❌ ничего |
| Искусств. флажолет | `⌥Y` | ❌ ничего |

Остальные подсказки честные: `⇧H` (фразировка), `⌥S` (shift-слайд), `⌥V` (широкое вибрато), `:` (сильный акцент), `!` (стаккато) — работают.

Это худший вид «неудобно»: человек читает подсказку, жмёт клавишу, ничего не происходит и он не понимает, кто виноват — он или программа.

**Что должен сделать агент:** либо довести эти четыре клавиши, либо убрать их из подсказок. Первое лучше: обработка приёмов уже есть (`tabTechKey`, строка 20911, и палитра вызывает те же функции).

## 5. Мелочи, которые заметны в работе

1. **`ƒ` под каждой долей.** В редакторе и в экспортированном `.gp5` у всех долей `dynamics = 5` (forte). Динамику никто не задавал, а в Guitar Pro она будет видна под каждой нотой. Проверено чтением файла.
2. **Пустые такты в экспорте — это не баг.** Один аккордовый квадрат занимает в песне 4 такта (он и на экране нарисован четырьмя клетками), плюс 1 такт таб-вставки = 5 тактов в файле; табы стоят в 5-м. Цифры в §6.
3. **Шапка стана читается хорошо** («такт 1, доля 1 · струна 6 · 1/4») — это лучше, чем счётчик в панели; её и надо оставить, даже если панель вернут.

## 6. Экспорт: блокеры E4 закрыты (проверено числами)

Сценарий: вставка из 4 нот — 6-я струна лады 0 и 3, 5-я струна лады 0 и 3 (пентатоника «Going to the Run»), 4 доли по 1/4.

### 6.1. `.gp5` — читается настоящим alphaTab 1.8.4

```
нот в файле:        4 из 4
струны:             1 и 2 (в модели alphaTab; это 6-я и 5-я гитарные)
лады:               0, 3, 0, 3
звучание (MIDI):    40, 43, 45, 48  = E2 G2 A2 C3   ✔ ровно то, что набрано
строй:              64,59,55,50,45,40 = E2 A2 D3 G3 B3 E4  ✔ живой строй песни, не пресет
тактов:             5  = 4 такта аккордового квадрата + 1 такт вставки
```

Прошлый дефект B1 (струны сдвинуты на одну, последняя терялась) — **исправлен**: раньше 6 нот на шести струнах давали 5 нот со сдвигом; теперь струна пишется как есть (`string: note.string`, строка 73089), и обратное чтение даёт ту же струну.

### 6.2. `.mid` — настоящий SMF

```
формат:             1 (как в GP: File → Export → MIDI)
дорожек:            2 — conductor (темп/размер/секции) + гитара
тиков на четверть:  960
нот:                4 — 40, 43, 45, 48 на 15360 / 16320 / 17280 / 18240 тиках
потери в отчёте:    только «MIDI не хранит аппликатуры, номера струн, звук…»
```

### 6.3. Обратный импорт `.gp5` в STRUCHORD

## 7. Задание агенту

Формулировки можно копировать в чат целиком. Порядок — по приоритету; P0 без остального не имеет смысла.

### P0-1. ⌥↑/⌥↓ — перенос ноты на соседнюю струну
- Ветка `event.altKey` в `tabGpKey` (около строки 22277) сейчас обрабатывает только ←/→ и на ↑/↓ возвращает `false`.
- Добавить: ⌥↑ = струна выше (в модели `string` **+1**, к 1-й), ⌥↓ = струна ниже (`string` **−1**, к 6-й) — как «Move Up / Move Down» в GP8. В 0.679 `string: 0` — это 6-я струна, и обычная `↑` уже увеличивает `string`; ⌥↑ должно вести себя так же, но не двигая курсор по времени.
- Лад сохранять. Если выделение есть — двигать все ноты выделения. Границы 0…5, за границей — тихо ничего.
- Правку делать через `tabGpEdit`, звук — `playTabNote`, как у ⌥+←/→.
- **Приёмка:** «3» на 6-й → ⌥↑ → 5-я струна, лад 3, звук. Четыре ⌥↑ подряд — 2-я струна. На 1-й струне ⌥↑ молчит.

### P0-2. Удаление такта как в GP
- `Ctrl+Del` → `tabGpDeleteBar` (на Mac `⌃-` уже работает, но `Ctrl+Del` в GP есть — пусть работают оба; удобно добавить и `⌘Backspace`).
- `Shift+Del` → удалить доли (`tabGpDelete(e, true)`).
- `⇧⌘→` / `⇧⌘←` — выделение тактов; `Ctrl+Del` по выделению удаляет все выделенные такты; `Esc` снимает.
- `Backspace` без модификаторов — удалить ноту (в GP это Delete Note), а не ставить паузу.
- **Приёмка:** 2 такта, во втором нота → `Ctrl+Del` на первом → один такт, нота цела, ⌘Z возвращает оба.

### P0-3. Пробел = play/pause, а не «Отмена»
- Причина: фокус на кнопке «Отмена» после открытия.
- Ставить фокус на `tabAtHostEl`, ловить `Space` с `preventDefault`, играть вставку; `⇧Space` — с начала.
- **Приёмка:** набрали 4 ноты, 10 раз пробел — редактор открыт, ноты целы, звук играет и останавливается.

### P1-4. Вернуть панель на компьютере
- Снять `display:none` для `.tab-tools` в медиазапросе (строка 5354) или показать только строку курсора (струна/доля/длительность) и кнопки «Такт ±», «Доля ±», «Выделить», буфер.
- Вернуть индикатор «6 (6-я)».
- **Приёмка:** 1600×1000 — кнопки видны и работают мышью; 1280×800 — ничего не наезжает; подсказка внизу не обрезана.

### P1-5. `Shift+↑/↓` = Select Beat
- Двигать фокус выделения по струнам, якорь не трогать; в модели — прямоугольник «доли × струны». `Delete` по такому выделению удаляет все попавшие ноты.

### P1-6. Клавиши, которым нужна только привязка (4 клавиши)
Приём в модели уже есть, кнопка в палитре есть — не хватает обработки в `tabTechKey` (строка 20911):

| Клавиша | Приём | Состояние |
|---|---|---|
| `L` | лига ноты (`tie`) | кнопка «Лига» есть, клавиша молчит |
| `⇧L` | лига доли (`tie-beat`) | кнопка «Лиги позиции» есть |
| `B` | бенд — открыть «Бенд…» | кнопка есть |
| `⌥Y` | искусственный флажолет | кнопка есть |

**Приёмка:** каждая клавиша ставит приём на ноту под курсором и снимается повторным нажатием; состояние видно на стане; `L` на ноте без соседней ноты справа показывает понятное сообщение, как это уже делает ошибка `tabGpError`.

### P2-7. Приёмы, которых нет в модели (новая работа, не клавиши)
`⇧I` баррэ, `⌘D/⌘U` бруски, `⇧⌘D/⇧⌘U` арпеджио, `⇧D/⇧U` пик-штрихи, `N` трель, `F` фермата, `⇧R` расгеадо, `$`/`)`/`(` слэп и тэппинг.

Это отдельные задачи: сначала поле в модели ноты, потом отрисовка на стане, потом клавиша. Делать после P0 и P1 — они не нужны для сценария «4 ноты перед Em».

### P2-8. Прочее из таблицы GP
`C` — копия последней доли, `T` — текст, `A` — аккорд, `[` / `]` — репризы, `⇧5` — повтор такта, `F4` — проверка длительности такта, `Esc` — снять выделение.

### P2-9. Косметика
- Не ставить динамику `f` по умолчанию (в модели и в `.gp5`).
- Подсказку переписать по-человечески и не обрезать.
- Масштаб стана (⌘+/⌘− или Ctrl+колесо).
- Если в черновике есть ноты, `Esc` спрашивает «Отменить ввод?».

### P2-10. Импорт
Импортированный `.gp5` показывает табы, а не пустые такты (§6.3).

## 8. Чеклист владельца: 5 минут

1. Новая песня → «+ Куплет» → «+ Таб». Поставьте «3» — нота на 6-й струне.
2. Нажмите **⌥↑** (Option+стрелка вверх). Нота должна переехать на 5-ю струну. *Сейчас — не переезжает.*
3. Поставьте ещё три ноты на той же 5-й струне: →, «5»; →, «5»; →, «7».
4. Нажмите **пробел**. Должна играть фраза, окно — остаться. *Сейчас окно закрывается вместе с нотами.*
5. Добавьте второй такт кнопкой «Такт +», поставьте в нём ноту и нажмите **Ctrl+Del** в первом такте. Первый такт должен исчезнуть. *Сейчас — ничего.*
6. `Shift+→` дважды, потом `Shift+↓`. Выделение должно «расти» вниз по струнам. *Сейчас — схлопывается в одну клетку.*
7. «Применить» → «Экспорт» → `.gp5` → откройте в Guitar Pro. Ноты должны стоять на 6-й и 5-й струнах в последнем такте секции.
8. Что написать агенту: «⌥↑/⌥↓ не переносит по струнам, Ctrl+Del не удаляет такт, пробел закрывает редактор, Shift+↓ ломает выделение. Панель кнопок на компьютере верни.»

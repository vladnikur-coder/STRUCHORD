# B-39 · хип-хоп вместо соул 0.802

## Решения R8 (до кода)

Владелец после слуховой приёмки 0.801 («звучит лучше, естественнее») и просмотра
карты жанров корпуса EZkeys выбрал замену: жанр «Соул» убирается из приложения,
«Хип-хоп» добавляется. Ответы опроса:

- **Старые песни с жанром soul:** «таких песен нет» — чистое удаление без
  legacy-пути. Если soul всё же встретится в чужом файле, санитайзер
  `cleanAuto` отбросит автонастройку как невалидный жанр (штатное поведение для
  неизвестных значений, без «зажатия»).
- **Корпус:** 14 не-хип-хоп soul-папок переклеиваются в ближайшие выжившие пулы
  (кандидаты фанк/поп) по измеренному сходству дескрипторов; soul-запись из
  `CORPUS_PROFILES` удаляется. Профили фанка/попа сдвинутся — только новые
  автопланы, сохранённые песни не перегенерируются.
- **Рисунки хип-хопа:** авторить новые (как для 9 жанров), по статистике
  корпуса: прямой grid-locked грув, луповый повтор, плотность соул-уровня,
  выдержанные аккорды.
- **Свинг:** выключен по умолчанию, прямой грув.

## Что изменилось

**keyboard-accompaniment.js.** В `STYLES` запись `['soul','Соул',…]` заменена на
`['hiphop','Хип-хоп',…]` с тремя новыми пресетами (`style-hiphop-0..2`):
«Стабы на сильных» `H···H··H`, «Бас и стабиль» `B···H··H·` (синкопы на «и»
второй и четвёртой долей), «Мелодичный луп» `B·t3·t5·t3·`. В `FAMILY_MOTIFS`
`soul` заменён на `hiphop` — пять связанных вариантов (вступление → аутро) с
нарастанием от половинного стаба к полному `['B','H']`-такту. `perform-hiphop-*`
выводятся автоматически. `presetSwing` остаётся только у blues/jazz — хип-хоп
прямой. Редактор аккомпанемента и диалог авто берут жанры из одного `STYLES`,
отдельных списков нет.

**STRUCHORD.html.**
- `AUTO_GENRES` (санитайзер): `'soul'` → `'hiphop'`; в приложении по-прежнему
  9 жанров.
- `GENRES` (модуль исполнения): `soul {chord:0.32, arp:0.21, offbeat:0.22,
  length:0.78}` → `hiphop {chord:0.52, arp:0.10, offbeat:0.14, length:0.88}` —
  больше блоковых стабов, меньше арпеджио, ровнее доли, длиннее выдержка.
- `GROOVES`: 4 новые двухтактовые строки хип-хопа
  `['C.....s.','C...p..s','C..s...s','C.s...p.']` — разрежённые лупы с
  синкопированными одиночными нотами.
- `GENRE_METRIC`: `soul:0.76` → `hiphop:0.95` — у хип-хопа доли ровные и
  прямые (в корпусе 17 % атак вне сетки против 31 % у соула).
- `CORPUS_PROFILES`: таблица пересобрана из корпуса — soul удалён, добавлен
  hiphop, фанк/поп поглотили переклеенные папки.
- Шапка: `ver 0.802`.

**sw.js.** `CACHE_NAME` → `struchord-v802` (пара к версии, R7).

## Корпус и маршрутизация

Билдер `dev/tools/build-b39-corpus-groove-profiles.py`: `APP_GENRES` без soul,
с `hiphop`. Хип-хоп-папки (`hip-hop`, `hip-hop#r&b`, `hip-hop_hooks`, 516
файлов) маршрутизируются в пул `hiphop`. Остальные 14 soul-папок (2 668 файлов)
распределены по измеренному расстоянию до выживших пулов-кандидатов (фанк/поп):
фазовый вектор L1 + z-оценки плотности/динамики/регистра по строкам
поддерживаемых метров:

- **→ фанк (5):** gospel, gospel_organ, soul_organ, retro_soul, rnb —
  грувовые, органные семьи.
- **→ поп (9):** classic_soul, contemporary_r&b, contemporary_soul_ballads,
  detroit_soul, ekx_soul_roads, modern_soul, neo_soul, r&b_themes,
  traditional_gospel — балладные и ровные семьи.

Профиль хип-хопа: 4/4 — 492 файла, 6/8 — 24 файла, 3/4 — 0 (честный fallback
агрегата, как у панка). Ролевых меток в именах хип-хоп-файлов нет (все
`unclassified` → custom), поэтому ролевые записи сводятся к агрегату жанра;
секции по-прежнему дифференцирует штатная `ROLE`-таблица генератора.
Характеристики пула: медиана 86 BPM, 14,75 нот/такт, off-grid 0,17,
повтор тактовых onset-подписей 50 %, полифония 2,74.

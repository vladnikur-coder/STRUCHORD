# B-105 · у повтора своя жизнь (0.777)

Волна выросла из приёмки 0.776: «на первый взгляд гораздо живее». Что ещё
выдавало секвенсор при уже живом тембре — **полное совпадение повторов**.
Один и тот же сэмпл, одна и та же громкость, один и тот же срез фильтра:
когда рисунок повторяет аккорд, слух слышит копию, а не второй удар.

## Что сделано

`keyboard-audio.js`, `playSample()`: у пианино и Rhodes скорость воспроизведения
умножается на `1 + detuneFor(mode, midi)`, где расстройка равномерно лежит в
±0,0035 (это ±6 центов). У органа и pad множитель не применяется: у органа
строй задаёт генератор, pad — подложка.

Ключевое решение — **детерминированность**. Расстройка считается от ноты и
номера повтора (`Math.sin(n·12.9898 + midi·78.233 + …)`), а не от `Math.random()`:

* одна и та же песня при каждом проигрывании звучит одинаково;
* экспорт MIDI/GP5 и офлайн-замеры остаются воспроизводимыми;
* тест может утверждать конкретные числа, а не «примерно так».

Громкость, ритм, высоты и длительности не менялись. Педаль 0.774, слои силы
и яркость от силы 0.776 работают как прежде: расстройка — множитель скорости,
а `loopAt` считается уже от итоговой скорости, поэтому петля Rhodes попадает
на то же место записи.

## Замер

Шесть одинаковых ударов ноты C4 (`renderSample`, уровень и сила одинаковые),
отклонение от точной высоты в центах:

| тембр | центы по ударам | размах |
|---|---|---|
| пианино | −5,4 / −4,0 / +3,9 / +2,9 / −3,8 / −0,7 | 9,3 |
| Rhodes | 99,0 / 95,9 / 101,2 / 100,8 / 98,6 / 99,9 | 5,3 |
| орган | 0 / 0 / 0 / 0 / 0 / 0 | 0 |
| pad | 0 / 0 / 0 / 0 / 0 / 0 | 0 |

Rhodes стоит около 100 центов потому, что ближайшая запись — на полутон ниже
C4 (транспозиция +1 полутон); важен размах, а не сдвиг.

## Ограничения

* Слышимость: ±6 центов на одиночной ноте не читается как фальшь, но аккорд
  из четырёх повторов перестаёт звучать «одним файлом». Больше 10 центов не
  поднимать — на длинных выдержанных нотах это уже строй.
* Расстройка общая на все дорожки и каналы: счётчик повторов один на
  `mode:midi`. Для двух клавишных дорожек с одним тембром это значит, что их
  повторы тоже расходятся между собой — на слух это плюс, но помнить стоит.
* Сброса счётчика при `stopAll` нет специально: иначе после каждой остановки
  первый удар снова совпадал бы с первым ударом прошлого прохода.

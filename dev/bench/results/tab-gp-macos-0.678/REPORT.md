# 0.678 · ввод GP8/macOS и тёмная тема

2026-10-22. Реализован [подтверждённый контракт](../../../specs/tab-insert/approved-decisions.md#0678--gp8macos-выделение-буфер-и-ошибки-черновика-r8-2026-10-22). **B-12.12 остаётся открытой.**

## Результат

- Удаление ноты сохраняет её время как ghost-паузу; остальные струны созвучия не исчезают.
- Insert позиции — после занятой, на паузе/в пустоте — под курсором. Цифра по-прежнему заменяет лад/добавляет струну, без автоперехода.
- Paste без выделения: `3—5—7—9` → `3—5—7—[3—5]—9`. Paste поверх выделенных `7—9` заменяет их на `3—5`.
- Диапазоны: Shift+стрелки, Shift-click, drag; на сенсорном экране — кнопка «Выделить», стрелки и тапы. Копируются целые позиции по всем шести струнам.
- Настоящие browser ClipboardEvents и системный буфер; типизированный JSON, проверка входа, пересчёт длительности при смене знаменателя. Экранные кнопки используют Clipboard API, с явным внутренним fallback при запрете доступа. Запоздалое чтение не вставляет ноты в уже другой черновик/курсор.
- Полностью пустая → сразу переходит в следующий такт при любой вводимой длительности; максимум четыре такта. Home/End и команды нот/позиций/тактов — в [согласованном контракте](../../../specs/tab-insert/approved-decisions.md#0678--gp8macos-выделение-буфер-и-ошибки-черновика-r8-2026-10-22).
- Ошибочный ритм остаётся в локальном черновике: видны все позиции, подпись над станом и пунктир такта. Apply заблокирован и повторно проверяется обработчиком, включая искусственный click на disabled-кнопке. Ноты не режутся/не выбрасываются для сохранения.
- Undo/Redo восстанавливают данные, курсор и диапазон; две цифры — одно действие. Сохранены первый общий Undo новой вставки и защита от чужой правки песни.

## Светлая и тёмная тема

Native SVG alphaTab получает цвета текста/линий из токенов темы. Раньше CSS-фон не перекрашивал явно заданные SVG-цвета. Ghost-паузы, диапазон, курсор, ошибка и кнопки используют ту же палитру; смена темы обновляет открытый стан.

| Телефон, 390 × 844 | [кадр](390-light.png) | [кадр](390-dark.png) |
| Сенсорный планшет, 1024 × 768 | [кадр](1024-light.png) | [кадр](1024-dark.png) |

Кадры показывают одновременно ghost-паузу, выделение и ошибочный ритм. Нижние кнопки остаются доступны, стан не требует горизонтальной прокрутки; пояснение ошибки находится над ним, не под длинной панелью.

## Границы доказательств

- Проверялась настоящая страница в Chromium/Linux, включая системный clipboard. Cmd-последовательности воспроизведены как Meta; штатный clipboard-путь браузера дополнительно проверен реальными Ctrl+C/X/V этой платформы. **Native GP8 и macOS Safari не запускались**, полной идентичности всему GP8 не заявлено.
- Это музыкальный clipboard STRUCHORD, **не бинарный формат буфера Guitar Pro**. Запрет Clipboard API в браузере/iframe обрабатывается явно, а не скрытой вставкой старого системного текста.
- Один голос, шесть струн, 1–4 такта; схема песни 9 и экспортные кодеки не менялись. Старая валидная нота через тактовую черту либо промежуток вне поддерживаемой сетки открывается в резервном списке с пояснением, без округления/потери исходника. Редактирование лиг не заявляется.
- Нет новых многотысячных JSON-дампов. В Git — тесты, этот краткий отчёт, однострочная сводка каждого сьюта и шесть необходимых кадров. Старые артефакты не удалены.

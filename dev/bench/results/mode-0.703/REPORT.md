# B-39 «Чистота режима» — 0.703

Владелец назвал четыре проблемы после 0.702. Здесь закрыты три из них (четвёртая — «обращения» — отдельная волна).

## Что было не так и что стало

| Проблема | Было | Стало |
|---|---|---|
| Панели налезают друг на друга | микшер, клавиатура и аккомпанемент открывались каждый сам по себе и перекрывали друг друга | открытие любого окна закрывает прежнее — всегда видно ровно одно |
| На гитарной дорожке клавишные кнопки | «Клавиатура» и «Аккомпанемент» висели на гитаре и даже в песне без дорожек | на гитаре их нет вовсе; в песне без дорожек — гитарный набор, как до волны |
| На клавишной дорожке гитарное | кнопки боя оставались (переименованные в «аккомп.») | боя нет; «Таб» остаётся — таб-вставка принадлежит песне, а не дорожке |
| Полоса воспроизведения | длинные подписи вылезали за круглую кнопку, на 1440 px уезжали во второй ряд, эмодзи 🎹/🎼 рисовались квадратами | у кнопок SVG-иконки; «Дорожки»/«Клавиши» остались подписями; полоса в один ряд на 1440, 1024 и 390 px |

## Как сделано

- `window.__b39PanelHub` — маленький узел (register / opened / closed). Каждое окно волны регистрирует свою функцию закрытия и сообщает об открытии. Внутренности окон не переписывались.
- Режим — класс `html.b39-keys-mode`, его ставит `relabel()` вместе с подписями. Правила вида:
  `html:not(.b39-keys-mode) #b39KeysBtn { display: none }` и
  `html.b39-keys-mode .chord-btn-strum { display: none }`.
- Клавишные окна закрываются сами, когда активной становится гитарная дорожка.

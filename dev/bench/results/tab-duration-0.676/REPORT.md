# 0.676 · направление +/− как в GP8

**2026-10-22.** По R8 владелец подтвердил обе пары: основную клавиатуру и цифровой блок. Только исправление направления длительности, не реализация остальных замечаний аудита GP8.

## Изменение

| Клавиша | Теперь |
| --- | --- |
| `+`, `=`, Numpad `+` | Укоротить: четверть → восьмая |
| `−`, Numpad `−` | Удлинить: четверть → половинная |

В обработчике диалога «Таб-вставка» поменяны местами два аргумента `tabAtChangeDuration`. Функция длительности, панель кнопок, стрелки, Ctrl+Y, Home/End, Insert и удаление позиций не менялись. Курсор не продвигается. Верхний предел — 1/1, нижний — 1/64.

## Проверки на финальной сборке

- Новый постоянный `dev/tests/b12-tab-duration-keys-browser.js`: **107 ok / 0 FAIL**. [Измерения](checks.json), [лог](duration-tests.txt).
  - `=`, `Shift+=`, Numpad `+`, основной и цифровой минус.
  - Каждая клавиша на обычных нотах, с точкой, с триолью, с обоими знаками.
  - Две струны созвучия меняют общую длительность, лады и знаки сохраняются, начало следующей ноты сдвигается на правильную эффективную длительность.
  - После каждой правки курсор остаётся на месте; одно Undo возвращает исходные ноты, Redo — изменённые.
  - Границы 1/1 и 1/64, выбор длительности в пустом месте, последующий ввод без автоперехода и прежний шаг стрелок.
- Тест сначала запущен **до исправления**: воспроизведено ошибочное превращение четверти в половинную клавишей `=`. [Первичный сбой](before-fix.txt).
- Регрессия курсора: **112 ok / 0 FAIL**, [лог](cursor-regression.txt).
- Живой стенд редактора: **46 ok / 0 FAIL**, [лог](legacy-regression.txt). В нём исправлено прежнее ошибочное ожидание «минус укорачивает»; теперь тот же сценарий выполняется `=`, затем минусом возвращает четверть.
- [page-integrity](page-integrity.txt) и [SW/версия](sw-gate.txt): **ALL OK**.
- [Синтаксис](syntax.txt): 9 исполняемых скриптов, 6 инертных блоков, 0 ошибок.

Проверки — настоящий Chromium, действия — клавиатурные события. Физический Numpad и установленный Guitar Pro не запускались. Полный набор из 152 тестовых файлов в этой узкой правке **не запускался**; перечислены только фактически выполненные проверки. Исторический аудит 0.675 не переписан: устранено только его замечание D1.

# 0.670 · B-12.12: стан alphaTab в редакторе «Таб-вставка»

**Промежуточный этап. Волна B-12.12 не закрыта.**

Строка нот в редакторе вставки заменена тем же движком, который рисует «Партии» —
alphaTab. Модель песни не менялась: в квадрате по-прежнему лежит массив `notes`
с полями `start`, `dur`, `dots`, `triplet`, `string`, `fret`, `pause`. alphaTab —

## Что появилось

* **Стан.** Одна таб-дорожка, 1–4 такта, без стандартного стана и без левой
  палитры; строка растягивается на ширину окна (`justifyLastSystem`), на узком
  экране масштаб понижается до полного вписывания (7 ступеней 1.15 → 0.52).
* **Курсор.** Вертикаль на доле, точка на струне и метка «такт · доля · струна».
  Точка прижимается к краям, чтобы подпись не обрезалась.
* **Панель для телефона и планшета.** Десять цифр лада (на узком экране 5 колонок,
  высота клавиши 53 px), `↑`/`↓` струны с подписью текущей, длительности
  1/1…1/64, Точка, Триоль, Пауза, Удалить, `↶`/`↷`, подсказка по клавишам.
* **Клавиатура.** Цифры лада (вторая цифра в течение 0,7 с даёт 10–24 и это
  один шаг отмены), `←`/`→` доля, `↑`/`↓` струна, `R` пауза, `−`/`=` длительность,
  `.` точка, `/` триоль, `Delete`/`Backspace` удаление, `Ctrl+Z` / `Ctrl+Shift+Z`
  отмена и повтор черновика, `Esc` закрытие.
* **Мышь и тап.** Клик по доле или по ноте ставит курсор туда; следующий ввод
  пишется в это место и на ту струну, по которой попали.
* **Резерв.** Если alphaTab недоступен (тесты, очень старый браузер), под станом
  раскрывается прежний простой список нот. Принудительно: `?tabfallback=1`.

## Что проверено на живом Chromium

35 проверок стенда, все зелёные:

1. стан построен и укладывается в ширину контейнера без горизонтальной прокрутки;
2. цифра ставит ноту нужного лада на шестой струне, курсор после ввода не уезжает;
3. `→` двигает на соседнюю долю, ввод пишется туда;
4. две цифры подряд дают лад 12 и **один** шаг истории;
5. `↑`/`↓` переносят курсор, и следующая нота встаёт на новую струну
   (прежний баг «нота осталась на нижней струне» не воспроизводится);
6. клик по стану переносит курсор в место клика, ввод создаёт ноту там;
7. `Delete` удаляет ноту под курсором;
8. `R` ставит и снимает паузу;
9. 1/8 применяется к новой ноте, панель показывает активную длительность;
10. точка (`dots: 1`) и триоль (`triplet: true`) попадают в модель;
11. `Ctrl+Z` / `Ctrl+Shift+Z` отменяют и возвращают правку черновика;
12. «Применить» переносит ноты в песню, повторное открытие показывает те же ноты;
13. на экране 390 px нет прокрутки страницы, стан 290 px, клавиши 35×53 в 5 колонок;
14. тапы по цифре, по `↑` и по 1/16 работают и дают ожидаемые ноты.

Замеры десктопа (1280×900): контейнер 573 px, стан 572 px, масштаб 1.15,
один такт 4/4, стартовый курсор — первая доля шестой струны, активна 1/4.

## Найденные и исправленные по ходу ошибки

* `tabAtFitWidth` сравнивал ширину обёртки, а она всегда равна ширине хоста:
  масштаб уходил в 0.52 и стан сплющивался в 7 px. Теперь признак переполнения —
  `scrollWidth > clientWidth`.
* Один такт — одновременно первая и последняя система; без `justifyLastSystem`
  alphaTab оставлял справа пустое место, и клик по пустоте уводил курсор в конец.
* Кнопки `↑`/`↓` имели `data-tab-string`, тот же атрибут есть у линий старого
  SVG-таба в ленте: клик по кнопке попадал в чужой элемент. Переименовано в
  `data-tab-string-step`.
* alphaTab в этой раскладке нумерует струны снизу вверх (нижняя линия — 1),
  поэтому модель 0 (низкая струна) теперь отображается как `string = модель + 1`;
  проверено кадром `e12-six-strings.png` — лады 0…5 идут снизу вверх.
* Вторая цифра лада больше не создаёт отдельный шаг отмены.
* Новая нота больше не «пропадает», если предыдущая тянулась через её долю:
  предыдущая подрезается до свободного места, а длительность новой ограничивается
  следующей нотой (иначе модель с одним голосом отбрасывала бы ноту).
* Метка курсора прижимается к станy по фактической ширине текста.
* `Ctrl+Shift+Z` не срабатывал: при Shift `event.key` приходит как `Z`.

## Как повторить

```bash
cd /home/user/STRUCHORD
python3 -m http.server 8000 --bind 0.0.0.0      # из корня репозитория
LD_LIBRARY_PATH=/tmp/libs/lib node dev/bench/tab-editor-0.670-live.js
node dev/tests/b12-tab-insert.js
node dev/tests/b12-tab-insert-foundation.js
```

  LD_LIBRARY_PATH=/tmp/libs/lib node dev/bench/tab-insert-foundation-live.js
